# Khuất Bá Tình - 3D Portfolio

Chào mừng bạn đến với mã nguồn trang web Portfolio cá nhân của tôi! Đây là một dự án web tương tác 3D được xây dựng để giới thiệu bản thân, kỹ năng và các dự án tiêu biểu mà tôi đã thực hiện.

## 🚀 Công nghệ sử dụng
Dự án được xây dựng dựa trên các công nghệ hiện đại nhằm tối ưu hóa hiệu suất và trải nghiệm người dùng:
- **Frontend Framework:** React.js (Vite)
- **Hiệu ứng 3D:** Three.js & React Three Fiber
- **Styling:** Tailwind CSS & Framer Motion
- **Gửi Email:** EmailJS

## 🛠 Cách chạy dự án trên máy tính của bạn
1. Cài đặt các thư viện phụ thuộc:
   ```bash
   npm install
   ```
2. Chạy máy chủ phát triển (Development Server):
   ```bash
   npm run dev
   ```
3. Mở trình duyệt và truy cập: `http://localhost:5173/`
